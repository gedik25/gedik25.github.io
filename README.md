# Muhammet Ali Gedik - Kişisel Portfolyo Sitesi

Bu proje, kişisel tanıtım ve portfolyo web sitesidir. Saf HTML5 + CSS3 + JavaScript ile geliştirilmiştir, herhangi bir framework kullanılmamıştır.

**Canlı Site:** https://gedik25.github.io

## Proje Hakkında
GitHub Pages üzerinde yayınlanan kişisel portfolyo sitesidir. Modern tasarıma, koyu/açık tema desteğine ve dinamik animasyonlara sahiptir.

## Sayfalar
- **index.html** — Ana Sayfa (giriş, hızlı bağlantı kartları, dinamik proje listesi ve etkileşimli filtreleme)
- **about.html** — Hakkımda (biyografi, zaman çizelgesi, blockquote)
- **interests.html** — İlgi Alanlarım (ul, ol, dl listeleri)
- **contact.html** — İletişim (e-posta, GitHub, LinkedIn, iletişim formu)

## Teknolojiler
- HTML5 (Semantik Yapı, Responsive Düzen)
- CSS3 (Koyu/Açık Tema, Dinamik Parlayan Etiketler, Hover Efektleri, CSS Değişkenleri, Glassmorphism)
- JavaScript (Daktilo Efekti, İnteraktif Proje Filtreleme, Reveal Kayma Animasyonları, Form İşleme)
